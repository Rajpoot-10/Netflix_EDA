# 🎬 Netflix Exploratory Data Analysis (EDA)

## 📌 Project Overview

This project performs an **Exploratory Data Analysis (EDA)** on the Netflix Titles dataset using Python. The objective is to clean the dataset, explore its characteristics, visualize important trends, and extract meaningful insights about Netflix's movies and TV shows.

The analysis covers data preprocessing, handling missing values, feature engineering, and multiple visualizations to better understand the content available on Netflix.

---

## 🎯 Objectives

* Understand the structure of the Netflix dataset.
* Clean and preprocess the data.
* Handle missing values appropriately.
* Explore the distribution of movies and TV shows.
* Analyze ratings, release years, countries, genres, and durations.
* Create informative visualizations.
* Extract business insights from the data.

## 🔍 Key Insights

* Movies make up a larger portion of Netflix's content than TV Shows.
* TV-MA is one of the most common content ratings.
* Most movies have durations between approximately 80 and 120 minutes.
* Netflix significantly expanded its content library during recent years.
* A small number of countries contribute a large share of the available titles.
